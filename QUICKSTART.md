# Quick Start: GoMixAPI + DeepSeek Harness

## 1. Get API Key
1. Sign up at https://gomixapi.com
2. Copy your API key (starts with sk-)
3. Get 5,000 free test tokens

## 2. Install DSH
Requires Node.js 22+.
```bash
npm install @deepseek-ai/dsh
```

## 3. Load Profile
```bash
export GOMIXAPI_API_KEY="sk-your-key"
npx @deepseek-ai/dsh web --profile gomixapi.profile.json
```

## 4. Choose Model
Pick GoMixAPI provider and one of 20 models.
